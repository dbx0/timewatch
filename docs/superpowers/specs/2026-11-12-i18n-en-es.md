# Idiomas: inglês e espanhol

Data: 2026-11-12. Pedido do usuário: "adicione agora versão em inglês e espanhol com padrão para o idioma do sistema".

## Comportamento
- Idiomas: Português (pt-BR), English (en), Español (es).
- Padrão: idioma do sistema. Detecção pelo locale do sistema operacional (Rust: crate `sys-locale` ou API do Tauri; frontend recebe o idioma resolvido do backend para que tudo use o mesmo). Regra: começa com `pt` → pt-BR; `es` → es; `en` → en; qualquer outro → en.
- Nova configuração **Idioma** em Configurações → Geral: "Automático (idioma do sistema)" (padrão), Português, English, Español — usando o Dropdown próprio. `Settings.language: "system" | "pt-BR" | "en" | "es"`, default `"system"` (campo com `#[serde(default)]` para dados antigos).
- Trocar o idioma aplica na hora em todas as janelas abertas (notch, horas, configurações, onboarding), no menu da bandeja, nos títulos das janelas e nas mensagens geradas pelo Rust (erros do Tracker, avisos, exportações). Evento `settings://language` ou reaproveitar `tracker://changed` + refetch.
- O onboarding também tem o seletor de idioma no primeiro passo (pequeno, no canto), já mostrando o idioma detectado.

## O que traduzir
- Todo texto de `src/i18n/pt-BR.ts` → criar `en.ts` e `es.ts` com as mesmas chaves (tipagem: as chaves de `pt-BR` são o tipo; faltar chave é erro de compilação).
- Textos do Rust: `src-tauri/src/i18n.rs` vira um módulo com os três idiomas (mensagens de `TrackerError`, notices do Tracker como "O relógio foi parado às HH:MM…", rótulos das exportações, menu da bandeja "Abrir/Ver semana/Configurações/Sair", títulos das janelas, texto do pill quando pausado). O Tracker/exports recebem o idioma resolvido (não leem locale diretamente) para continuar testáveis.
- Nomes de dias e meses (Seg/Mon/Lun, "nov") por idioma.

## Formatos por idioma
- Horas decimais: pt-BR e es usam vírgula (`5,5`); en usa ponto (`5.5`). Vale para a grade, cópia ao clicar e exportações.
- CSV: pt-BR e es mantêm separador `;` com vírgula decimal; en usa separador `,` com ponto decimal. Cabeçalhos traduzidos (en: `date,client,project,regular_hours,overtime_hours,total_hours` / detalhado `date,client,project,start,end,hours,note`; es: `fecha;cliente;proyecto;horas_normales;horas_extra;horas_total` / `fecha;cliente;proyecto;inicio;fin;horas;nota`). Datas continuam ISO.
- Horários continuam 24h (HH:MM) nos três idiomas (decisão do Claude: consistente com o produto; pode virar opção depois).
- HTML exportado no idioma atual, com `lang` correto.

## Qualidade das traduções
Traduções naturais, curtas, no mesmo tom do português (informal, direto). Termos: jornada → en "workday", es "jornada"; hora extra → en "overtime", es "horas extra"; notch → "notch" nos três.
